# Projekty Lidertax

Repozytorium na projekty wspierające pracę Lidertax.

## Cel

To miejsce służy do bezpiecznego przechowywania kodu, notatek technicznych, automatyzacji i eksperymentów związanych z rozwojem narzędzi dla Lidertax.

## Zasady pracy

- Używamy kodowania UTF-8, żeby polskie znaki działały poprawnie.
- Nie zapisujemy w repozytorium haseł, tokenów, kluczy API ani plików `.env`.
- Większe zmiany opisujemy krótkim commitem.
- Projekty i eksperymenty trzymamy w osobnych folderach.

## Proponowana struktura

```text
projekty/
  nazwa-projektu/
    README.md
docs/
  notatki.md
```
